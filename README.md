# Another Round

**Another Round** - A boxing-themed focus timer extension for Raycast. Knock out procrastination with focused work rounds, achievement tracking, and productivity insights.

## 🥊 Features

- **Boxing-Themed Focus Sessions**: Each work session is a "round" in your fight against procrastination
- **Achievement System**: Unlock boxing-themed achievements and climb the championship ranks
- **Mood Tracking**: Track your energy and focus levels before and after each round
- **Session History**: Review your training history and victories
- **ADHD-Friendly**: Designed with ADHD-friendly features for better focus and motivation

## Installation

```bash
pnpm install
pnpm run dev
```

## Usage

Type "Focus Session" in Raycast to start another round of focused work.
